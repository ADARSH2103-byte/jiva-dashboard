# Jiva Dashboard

A modern and responsive dashboard application built using React.js.  
This project displays user data, summary cards, tables, and analytics in a clean UI.

---

## 🚀 Features

- Responsive Dashboard UI
- Sidebar Navigation
- User Details Page
- Summary Cards
- Dynamic Tables
- React Router Navigation
- Reusable Components
- Clean Folder Structure

---

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- Tailwind CSS
- React Router DOM

---

## 📂 Project Structure

bash src/  ├── components/  ├── pages/  ├── data/  ├── assets/  ├── App.jsx  └── main.jsx 

---

## ⚙️ Installation

Clone the repository:

bash git clone <repository-url> 

Move to project folder:

bash cd jiva-dashboard 

Install dependencies:

bash npm install 

Start development server:

bash npm run dev
